# Number-Hunt

A simple **console-based Number Guessing Game** developed using Java.

The computer randomly generates a number between **1 and 100**, and the player tries to guess it. After each incorrect guess, the program provides a hint indicating whether the guessed number is **greater than** or **less than** the target number.

## 🚀 Features

* Generates a random number between 1 and 100
* Accepts user guesses through the console
* Provides higher/lower hints
* Counts the number of attempts
* Displays a success message when the correct number is guessed

## 🛠️ Technologies Used

* **Java**
* `Scanner` – for user input
* `Random` – for generating the target number
* `while` loop – for repeated guesses
* `if-else` – for comparing the guess with the target
